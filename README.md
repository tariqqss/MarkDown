## 🧠 Чому це важливо

Markdown — це простий спосіб оформлювати текст. Він потрібен для:

- README файлів у репозиторіях;
- записів, конспектів і пояснень;
- документів, де треба робити заголовки, списки і виділення;
- красивого оформлення коду й інструкцій.

Тобто Markdown допомагає робити текст зрозумілим і чистим.

## 📝 Основні можливості Markdown

### Заголовки

Markdown дозволяє робити заголовки різного рівня:

# Заголовок 1
## Заголовок 2
### Заголовок 3
#### Заголовок 4

### Жирний і курсивний текст

- Це жирний текст: **важливо**
- Це курсив: *зверніть увагу*
- А це одночасно: **_обидва стилі_**

## 🐍 Простий приклад на Python

```python
name = "Тарас"
print(f"Привіт, {name}!")
print("Це мій перший код на Python.")
```

Результат буде таким:

```text
Привіт, Тарас!
Це мій перший код на Python.
```

Цей код дуже простий, але вже показує, як працює Python.
